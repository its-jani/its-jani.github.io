# Shaik Jani Basha — Personal Portfolio Website

🌐 **Live Website:** [https://its-jani.github.io/](https://its-jani.github.io/)

A modern, responsive personal developer portfolio showcasing academic background, data science & software projects, skills, certifications, and technical profiles. Built with pure HTML5, vanilla CSS3, and modern JavaScript adhering to Material You and minimalist design aesthetics.

You can view the live portfolio anytime at:

---

## ✨ Features

- **Material You Aesthetic & Minimalist Styling**: Clean typography, frosted glass floating navigation bar, bento grids, and interactive cards.
- **Theme Switching**: Seamless Light / Dark theme mode toggle with system preference detection and local storage persistence.
- **Responsive on All Devices**: Fluid design adapted for desktop, tablet, and mobile screens with a custom hamburger navigation drawer.
- **Cross-Platform Favicons & PWA Ready**: Custom multi-resolution app icons for standard desktop browsers, iOS touch screens, Android chrome devices, and a `site.webmanifest`.
- **Smooth Navigation & Scroll Spy**: Intersection Observer-based active link indicator with smooth scroll targeting and top-of-page return on home navigation.
- **Comprehensive Sections**:
  - **Hero Section**: Bio, direct action buttons, live availability indicator, and visual profile card.
  - **About & Bento Highlights**: Academic background (B.Tech in CSE - Data Science at KITS Guntur), technical focus areas, and quick facts.
  - **Tech Stack & Skills**: Categorized chips covering programming languages, libraries, tools, and platforms.
  - **Education & Experience**: Interactive chronological timeline with course metrics and CGPA.
  - **Featured Projects**: Project cards with descriptions, key tech tags, live previews, and repository links.
  - **Profiles & Connect**: Direct links to GitHub, LinkedIn, LeetCode, CodeChef, and HackerRank.
  - **Contact**: Functional email and location connect options.

## 🛠️ Built With

- **HTML5**: Semantic markup, Open Graph tags, and accessibility attributes.

## 💻 Local Development

To run or preview this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/its-jani/its-jani.github.io.git
   cd its-jani.github.io
   ```

2. **Open in browser:**
   Simply double-click `index.html` or use any local static file server:
   ```bash
   # Using Python 3
   python -m http.server 8000

   # Or using Node.js / npx
   npx serve .
   ```

3. Open `http://localhost:8000` in your web browser.
